# Roadmap

## Phase 0 — Foundation

Status: In progress

- Project scaffold
- Documentation structure
- CI
- Testing foundation
- UI foundation
- Project standards

---

## Phase 1 — Assignment Understanding MVP

Goal:

Allow a student to create an assignment and understand what is required.

### Deliverables

- Assignment creation
- Task input
- Rubric input
- Instructions input
- Task analyzer
- Rubric analyzer
- Success criteria generation
- Basic assignment workspace

### Exit Criteria

Student can see:

- what the assignment asks
- what the rubric requires
- what outstanding work needs to demonstrate

---

## Phase 2 — Tough Reviewer MVP

Goal:

Review a completed draft.

### Deliverables

- Draft input
- Evidence reviewer
- Analysis reviewer
- Accuracy reviewer
- Structure reviewer
- Grammar reviewer
- Rubric mapper
- Priority improvement

### Exit Criteria

System can answer:

> "What are the three most important things preventing this work from reaching the top band?"

---

## Phase 3 — Revision Loop

Goal:

Support iterative improvement.

### Deliverables

- Draft versions
- Review history
- Revision checklist
- Re-review
- Final teacher attack

### Exit Criteria

Student can:

Draft
→ Review
→ Revise
→ Re-review
→ Final review

---

## Phase 4 — Subject Intelligence

Goal:

Improve review quality across subjects.

Initial subject frameworks:

- English
- History
- Legal Studies / Commerce
- Science

Subject reviewers should extend the core framework rather than duplicate the whole system.

---

## Phase 5 — Learning Over Time

Goal:

Identify recurring student weaknesses.

Potential capabilities:

- recurring analysis weaknesses
- evidence weaknesses
- grammar patterns
- rubric interpretation weaknesses
- improvement history

Example:

> "You consistently identify strong evidence but often stop before explaining why it matters."

---

## Phase 6 — Broader Product

Potential capabilities:

- multiple students
- parent accounts
- teacher collaboration
- classroom workflows
- richer research support
- additional year levels

These should not be implemented until the core review experience is proven.
