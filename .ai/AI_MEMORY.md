# AI Memory

## Purpose

Define what the AI system may remember across assignments.

The objective is to provide useful continuity without creating dependency or storing unnecessary personal information.

---

## Core Principle

> Remember learning patterns, not private personal details.

---

## Assignment-Level Memory

The system may remember:

- assignment title
- subject
- year level
- task requirements
- marking criteria
- review history
- draft versions
- identified weaknesses
- improvements made
- final review outcome

---

## Student Learning Memory

The system may maintain high-level academic patterns such as:

- tends to describe evidence without explaining significance
- strong evidence selection
- needs to strengthen conclusions
- frequently makes unsupported claims
- strong structure
- grammar patterns that recur

These observations should be framed as learning patterns rather than fixed characteristics.

---

## Memory Should Be Evidence-Based

Do not record:

> "Ammu is bad at analysis."

Prefer:

> "Across three reviewed assignments, the student often identifies relevant evidence but does not consistently explain its significance."

The second statement is:

- observable
- evidence-based
- actionable
- changeable

---

## Memory Should Support Future Feedback

If a recurring pattern is identified, future reviews may ask:

> "Last time we noticed that you were identifying good evidence but sometimes stopping before explaining why it mattered. Is that happening here too?"

This should be used to encourage independent self-review.

---

## Memory Categories

### Assignment Memory

Specific to one assignment.

### Subject Memory

Patterns within a subject.

### General Learning Pattern

Patterns observed across multiple assignments.

---

## Do Not Store

Do not intentionally store:

- sensitive personal information
- unnecessary family information
- private school information
- passwords or credentials
- irrelevant personal details
- speculative psychological assessments
- permanent labels about ability

---

## Student Control

Future versions should allow the student/parent to:

- view important remembered learning patterns
- correct inaccurate observations
- remove memories
- reset assignment history

---

## Memory Quality Rule

A memory should only be created when it is:

1. Useful for future academic support
2. Supported by observed work
3. Likely to remain relevant
4. Not unnecessarily personal

---

## Memory Is Not Assessment

The system must never treat previous AI assessments as authoritative school grades.

Teacher feedback and official school assessment remain authoritative.
