# Guiding Principle

Meetings should create clarity, not paperwork.

Every meeting should end with:

- Clear decisions.
- Assigned actions.
- Defined owners.
- Agreed next steps.

If no decision or action resulted, the meeting should have been an email or an asynchronous discussion.
